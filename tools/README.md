# PresentMon installation

Download a compatible **console executable** from the
[official PresentMon releases](https://github.com/GameTechDev/PresentMon/releases).
Put `PresentMon-*.exe` in this folder, or set an explicit executable path in
`config/cb_settings.ini`.

The settings supplied with ChickenBench use the PresentMon 2.x console flags.
Check the selected release's command-line help if they are rejected. The capture
application installer is a different download from the standalone console tool.

No executable is supplied by this repository. Local executables are ignored by
Git and excluded from the source ZIP builder. PresentMon remains subject to its
own license and notices; see the release you actually install.
